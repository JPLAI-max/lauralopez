session, and issues the sid cookie. The blank screen is a React
render crash on /admin. There is NO error boundary in the app,
so any thrown error unmounts the tree and leaves a white page
with no indication of what happened.

   Create components/ErrorBoundary.tsx (class component with
   componentDidCatch). Render the error message, the component
   stack, and a reload button. Wrap:

       kill the shell
     - the whole app in App.tsx as a last resort
   Log the error to console with full stack.

   Never let a crash present as a blank page again.

       empty

   Fix the actual thrown error. Report what it was.
